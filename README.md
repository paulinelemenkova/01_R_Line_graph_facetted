# R Line Graphs (ggplot2)

A collection of R line-graph scripts built with ggplot2, covering single and multi-series time series, colour-gradient lines, and side-by-side composition (patchwork). Example data are agricultural, forestry and trade statistics (FAOSTAT and national datasets).

## Scripts

- 2_line_color_gradient.R: line charts with continuous colour gradients (scale_color_gradient2 / scale_colour_steps2) of agricultural land and production-value series, plus patchwork side-by-side layout.

- ggplot_forestry.r, ggplot_Vietnam_export_quant.r, ggplot_Cuba_mag.r, ggplot_Mtq_*_.r, ggplot_LC_*_MODIS.r and others: line graphs of forestry, trade, social and land-cover series for various regions.

## Methods

- Time-series line plotting with continuous colour encoding, faceting and multi-panel composition (ggplot2, patchwork).

## Data

- FAOSTAT and national agricultural / forestry / trade CSVs (example data).

## Requirements

- R (>= 4.0); packages: ggplot2, dplyr, readr, patchwork
